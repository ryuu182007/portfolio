# 🚀 Featured Projects

## 🔐 ThreatSim — Insider Threat Behaviour Simulator

**Category:** Cybersecurity Web Project

ThreatSim is a cybersecurity-focused web project designed to simulate **insider threat behaviour** and visualize different employee activity patterns and security risks.

The project explores how different behaviours can be represented through a security-focused interface.

### Key Concepts

* 🔐 Insider Threats
* 👤 Employee Behaviour
* 🚨 Security Risks
* 📊 Behaviour Visualization
* 🧪 Scenario Simulation
* 🖥️ Cybersecurity Dashboard

### Purpose

The main purpose of ThreatSim is to create an interactive environment where different insider-threat scenarios can be represented and observed through a cybersecurity-oriented interface.

To run the portfolio on your computer:

```bash

```

### 2. Open the project

```bash

```

### 3. Run the website

You can open:

```text
index.html
```

directly in your browser.

For development, you can also use a local development server such as **VS Code Live Server**.
